PORTFOLIO WEBSITE — QUICK START
1. Open index.html in a browser.
2. Replace 'Your Name', initials YN, and experience/education placeholders in index.html.
3. Set your email in SITE.email in script.js; replace LinkedIn and GitHub URLs in index.html.
4. Add a real resume.pdf beside index.html to activate the resume download.
5. Put approved images in assets/ using filenames listed in script.js; the modal handles missing photos gracefully.
6. For a real contact form that sends without an email app, connect a service such as Formspree or a serverless endpoint.
7. Publish the folder with GitHub Pages, Netlify, or another static web host.
Note: Sample project summaries are illustrative and should be reviewed before publication.
